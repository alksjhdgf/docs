# WeatherApp-Codex

This directory is the application-source export of `output/WeatherAppHM` for the WeatherApp migration assessment (2026-10-12). It includes the HarmonyOS application and test sources, resources, Proto schemas, generated ETS source, package manifests, lockfiles, and Hvigor configuration.

Signing configuration and references were removed from `build-profile.json5`. No certificate, private-key store, signed HAP, or other installable build output is included. Configure signing separately if a signed build is needed.

Generated build caches, installed `oh_modules`, IDE state, migration evidence under `spec`, and research artifacts are not application source and are not included. Dependencies can be restored from the package manifests and lockfiles.
